# Security Policy

Report suspected vulnerabilities privately to the security address configured by the operator. Do not include customer data in reports. The operator should acknowledge within two business days, triage critical reports within one day, and coordinate remediation and disclosure.

The supported release is the current production deployment. Safe-harbor language and the actual contact address must be published before launch. Security controls include tenant-scoped queries, role checks, recent-authentication gates, scrypt password hashing, hashed bearer tokens, encrypted OAuth secrets, secure cookies, origin checks, restrictive headers, import limits, audit logs, non-root containers, automated tests, and restore checks.
